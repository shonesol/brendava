Firestore security rules

The console can only change what the database rules allow. Paste these in Firebase Console, Firestore Database, Rules, then Publish. They let only the two admin emails write, let visitors read public content, and let visitors submit reviews, messages and bookings only. Compare with your current rules before publishing.
